# 豆瓣三站搜索与片单排序

当前版本：**2.17.1**。撤销电影关系图谱，恢复2.16.0的三个搜索入口、IMDb/TMDB、自定义搜索站点、影片操作菜单、片单筛选排序与失败续载。

## 三站快捷搜索

在豆瓣影视标题旁显示：**搜中创 / 搜B站 / 搜夸克**。

- 支持想看、在看、看过列表（grid / list）、影视详情、电影首页、影视片单和动态新增条目。
- 三个入口统一优先使用页面提供的中文名，没有中文名时使用英文名。例如「怪形前传 The Thing」搜索「怪形前传」，「Spider-Man」搜索英文名。
- 支持斜杠别名、中英同排、中日同排和已知地区标注；保留正式名称中的 Re:、阿Q、X战警等。只解析页面已有名称，不联网翻译。
- 三个入口都是带真实地址的链接，支持中键、Ctrl/Meta/Shift点击和复制地址，当前豆瓣页保持不动；普通左击优先使用GM_openInTab。Enter/Space各打开一次，按住Space不会重复开页。
- 中创沿用既有的18字长关键词限制；B站与SoQuark不做此截断。
- 书籍等非影视条目、侧栏推荐和广告不会插入按钮。
- v2.14.1修复豆瓣原生链接颜色覆盖问题：搜B站为粉色实底、搜夸克为绿色实底，文字与背景分别适配亮暗模式，悬停和键盘聚焦也保持清晰。

## 更多操作

标题旁增加「更多 ▾」，其中包含：

- 复制片名：复制中文优先的原片名，不添加年份或删除季数；失败会提示。
- 三站一起搜：一次打开当前中创、B站、夸克三个搜索链接。浏览器弹窗策略可能影响未提供GM API时的多页打开。
- 搜索时加年份：默认关闭，按当前条目的上映年份附加，不重复添加已有年份；无年份时禁用。
- 搜索时保留季数：默认开启，可去掉/恢复末尾「第X季」或「Season X」；无季数时禁用。
- B站搜预告、B站搜解说：使用当前片名及年份/季数选项跳转搜索。
- IMDb / TMDB：当前影片资料中有准确编号/链接时直达条目，否则按当前片名搜索。详情页读取 `#info`，列表只读取当前条目，不抓取详情页或申请API密钥。评论和侧栏里的链接不作匹配依据。
- 自定义搜索站点：添加名称和搜索网址，如 `https://example.com/search?q={q}`，其中 `{q}` 自动替换为编码后的片名。支持启用/停用、上移/下移和删除，最多20个站点。入口按设置顺序显示在“更多”里；原三站按钮及“三站一起搜”保持现状。

菜单可用方向键移动、Escape关闭，也可点击外部关闭。年份和季数开关只对本页当前条目有效，刷新恢复默认。已完全删除关键词编辑弹窗、输入框及中英文手动切换；默认仍优先中文名，没有中文名时使用英文名。

在“更多 → 自定义搜索站点…”中填写后先点“添加站点”，再点“保存”。取消或Escape放弃本次修改。仅接受HTTP(S)搜索网址，片名占位符放在路径或查询参数中。站点配置跨豆瓣页面保留；刷新后年份/季数仍恢复默认。停用的站点会保留配置但不显示入口。

## 影视片单整单排序

适用于 `https://www.douban.com/doulist/{片单ID}/`，不绑定任何示例ID。

列表上方的「整单排序」提供：

- 评分：高到低 / 低到高。
- 年份：新到旧 / 旧到新。上映时间按影片简介里的年份。
- 原片单顺序。

首次选择排序或「应用筛选」时，按分页顺序加载完整片单，显示进度并支持「取消加载」。全部完成后才应用排序和筛选。失败、超时或取消时保留当前列表以及本页已成功读取的分页，点击「继续加载」从失败页恢复，不重复请求已经读取的页；刷新页面会清除续载进度。

工具栏支持**最低评分（0—10）与起止年份同时筛选**，两个条件必须同时满足。未填写的条件不限制；设置某字段条件后，该字段未知的影片不匹配。有筛选时不展示书籍等非影视条目。「清空筛选」恢复全部条目并保留当前排序；无匹配时显示0部，可以继续调整或清空条件。排序与筛选可组合使用，不会互相重置。

从中间页进入也会读取第一页至末页。保留当前原生筛选条件，例如「可播放」；需要所有条目时先切回豆瓣的「全部」。无评分/年份排末尾，同值保持原片单顺序，混合豆列中的书籍保留原槽位。

全量完成后隐藏原分页。后续切换排序使用本页内存；「原片单顺序」恢复完整片单的原始顺序。刷新页面恢复豆瓣原生分页。原生增删条目后需刷新再排序，避免旧缓存覆盖变更。

请求间隔约600ms，单请求超时20秒，最多读取1000页。大型片单需要更长等待时间。

## 本版移除的功能

已删除影视库、资源收集/解析/推荐/浮层、网盘链接管理、搜索/保存/观看状态、本地状态统计和状态筛选，以及中创页面的检测与状态回写。

原三个搜索按钮和片单排序不访问影片存储。打开“更多”时只读取独立设置键 `zcw.searchSites.v1`，保存站点配置时才写入该键，不记录影片、观看状态或搜索历史。过去版本的本地记录不会被读取、修改或清空。原「我的影视库」书签现在显示普通豆瓣首页。

## 安装或更新

1. 在浏览器中打开 Tampermonkey，编辑已有的「豆瓣想看 → 搜中创」脚本。
2. 用根目录 `douban-wish-to-zhongchuang.user.js` 的完整内容覆盖原脚本并保存。
3. 刷新豆瓣页面；已打开的旧页面需要刷新才会移除旧版界面。

首次使用时，在 Tampermonkey 中新建脚本，粘贴同一文件并保存即可。脚本保留原名称与命名空间，声明 `GM_openInTab`，以及保存站点设置所需的 `GM_getValue` / `GM_setValue`。从旧版升级时，油猴可能要求确认新增设置存储权限。

### 后续版本自动检查更新

本版已配置 `@updateURL` 和 `@downloadURL`，指向GitHub主分支。先打开一次[安装/更新脚本](https://raw.githubusercontent.com/kakaSheepA/douban-search-tools/main/douban-wish-to-zhongchuang.user.js)，在油猴中确认更新；也可以按上面的步骤覆盖完整脚本。

以后发布更高版本后，油猴会按自身更新检查设置获取版本，更新后刷新豆瓣生效。检查时机由油猴配置决定，**不是每次本地保存后立即更新**。可参考[Tampermonkey元数据说明](https://www.tampermonkey.net/documentation.php#meta:updateURL)。

当前浏览器工具禁止访问 `chrome-extension://` 页面，因此本次没有代替用户直接编辑已安装的油猴脚本，也不会绕过这一限制。

可在脚本顶部修改 `CONFIG.SEARCH_URL`、按钮文案和季数/标点清洗选项。调试可设 `CONFIG.DEBUG=true` 或在页面地址末尾追加 `#zcwdebug`。

当前测试涵盖页面识别、三站片名选择与跳转、动态注入、IMDb/TMDB精确/搜索回退、自定义站点配置与独立存储、全量片单排序及已删除功能不再出现。移除功能的旧1313断言套件已备份，不能作为当前版本的通过数量。历史阶段文档和 `release/` 冻结包保留作版本参考。

工作流探针使用真实豆瓣片单验证筛选与更多操作菜单，使用受控503页面验证失败续载。原生中键/Ctrl开页使用快速本地HTTP目的页隔离第三方网络延迟，实际三站地址另行核对；不将其表述为三家网站搜索结果已逐条验收。截图和结果输出至 `test/workflow-verification/`，不上传验证产物。

更多操作探针在隔离Chrome页面验证真实剪贴板读写、组合链接、三站一起搜、Escape焦点，以及亮暗和窄屏菜单布局。
